# 🌐 CompTIA Network+ (N10-009)

This section of the repository documents my study progress for the CompTIA Network+ certification.

## 📘 Overview

Network+ focuses on networking concepts, infrastructure, network operations, security, and troubleshooting. It covers the technologies and practical skills required to configure, manage, secure, and troubleshoot computer networks.

## 🎯 Objectives

- Understand networking concepts, models, protocols, and architectures
- Learn IP addressing, subnetting, routing, and switching
- Gain practical knowledge of network infrastructure and wireless technologies
- Understand network operations, monitoring, and security
- Develop structured network troubleshooting skills

## 🛠 Structure

Each module includes:

- **Key Concepts** → concise notes of important topics
- **Lab** → hands-on practice or recreated scenario
- **Troubleshooting Scenario** → real-world problem simulation
- **Reflection** → lessons learned and improvements

## 🚀 Goals

- Build a strong foundation in networking for IT support and systems administration roles
- Prepare for the CompTIA Network+ exam (N10-009)
- Develop practical networking and troubleshooting skills through hands-on labs
